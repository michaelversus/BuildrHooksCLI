# Emit content-free tool-start events

BuildrHooksCLI will emit a versioned, content-free tool-start event through the existing repository-local queue, capturing the observed attempt without affecting whether the agent may run the tool. The event carries only source-provided identity, tool name, declared execution surface when available, and CLI receipt time; invocation and subagent identities remain optional, and missing invocation identity is reconciled from transcript evidence. Codex subagent tool starts use the session identity supplied by Codex (the parent session where per-tool subagent identity is unavailable), while Claude subagent identity is carried separately when provided. Per-agent support is advertised additively in the existing capabilities schema, and older producers continue to rely on transcript evidence.
